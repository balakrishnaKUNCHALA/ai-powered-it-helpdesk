# AI-Powered IT Helpdesk Automation System

## Overview
A Streamlit web application for reporting IT issues,
classifying tickets, assigning priorities, and providing
basic troubleshooting suggestions.

## Features
- IT issue reporting
- Category and priority selection
- Ticket dashboard
- Ticket status management
- Troubleshooting suggestions

## Technologies
- Python
- Streamlit
- Visual Studio Code

## Run the Project
Install dependencies:

```bash
python -m pip install streamlit
```

Start the application:

```bash
python -m streamlit run app.py
```

## Current Status
Working prototype tested locally.
Troubleshooting suggestions currently use predefined rules,
not a connected live AI model.
