# AI-Powered IT Helpdesk - Prompt Documentation

## Prompt 1: Project Planning
Build a beginner-friendly IT Helpdesk web application using
Python and Streamlit.

## Prompt 2: Issue Classification
Create a function to classify IT issues into Network,
Hardware, Software, Login/Access, and General Support.

## Prompt 3: Priority Assignment
Assign Low, Medium, or High priority based on the reported issue.

## Prompt 4: Troubleshooting
Provide safe, predefined troubleshooting suggestions for each
issue category and recommend contacting IT support when needed.

## Prompt 5: Ticket Dashboard
Display ticket IDs, issue descriptions, categories, priorities,
and ticket statuses in a dashboard.

## Tools Used
- Python
- Streamlit
- Visual Studio Code

## Implementation Note
The current version uses rule-based classification and
troubleshooting. A live AI model is a planned future enhancement.
